## 数据更新流程

更新赛事结果只需编辑 `data/events.json`，应用会自动重新计算:

1. 各预测者的预测准确度
2. 赛段通过/失败状态
3. 排行榜排名变化
4. 赛事进度状态

无需修改代码，数据驱动一切!

## 瑞士轮规则

瑞士轮（Swiss）是 CS2 Major 前两个阶段使用的赛制。它没有固定对阵表，每一轮的对阵都由
「前面的比赛结果」推算出来，所以经常让人困惑：为什么这两队碰上了？为什么我猜的队伍突然排到后面了？

下面用大白话讲清楚它怎么运作。

### 一句话概括

> **战绩相同的队伍互打，谁也不许挑对手。**

赢 3 场晋级，输 3 场淘汰。16 支队伍要打 5 轮，打完产生 8 支晋级队伍。

### 第一步：分组

每轮开始前，先按当前战绩把队伍分组。

第 1 轮所有人都是 0-0，所以第 1 轮 = 一个 16 队大组。

第 2 轮就有了 1-0 和 0-1 两个组，各 8 队:

```
1-0 组: 赢了第一轮的 8 队   → 再赢就 2-0
0-1 组: 输了第一轮的 8 队   → 再输就 0-2
```

再往后组会越分越细。到第 4 轮，就会出现 `2-1`、`1-2` 这样的组；第 5 轮是最后一轮，
只剩 `2-2` 一个组，8 支队伍在打，赢的 4 支晋级，输的 4 支淘汰——所以第 5 轮一定是 bo3。

**规矩是死的: 2-1 的队伍只能打 2-1 的队伍，不可能去碰 1-2 的。**

### 第二步：组内排序

分组之后，组里这几支队伍谁排第一、谁排倒数第一？这就决定了谁跟谁打。

排序看四样东西，一个比不下去就比下一个:

| 顺序 | 比什么                   | 谁排前面 |
| ---- | ------------------------ | -------- |
| 1    | 负场                     | 负场少的 |
| 2    | 胜场                     | 胜场多的 |
| 3    | **Buchholz（对手强度）** | 分数高的 |
| 4    | 种子                     | 种子小的 |

注意: 在同一个组里，大家的战绩本来就是一样的（2-2 组的每支队伍都是 2-2），
所以前两项分不出胜负，**真正决定顺序的只有 Buchholz，Buchholz 再打平才看种子**。

### 第三步：Buchholz 是什么

> **Buchholz = 你所有对手的战绩「胜 − 负」，加起来。**

通俗说: **你打过的对手整体赢得多，说明你遇到的对手硬，你的分就高。**

这里的门道在于，算的是对手的**净胜场**，不是**胜场数**。

拿个真实例子。新加坡 2026 第一阶段第 5 轮，`2-2` 组（8 支队伍争最后 4 个名额，
这里只列 6 支）:

| 队伍     | 打过的对手            | 胜场和 | 净胜场和 |
| -------- | --------------------- | ------ | -------- |
| FaZe     | 1-3 / 3-1 / 3-0 / 3-1 | 10     | **+5**   |
| M80      | 3-1 / 3-0 / 1-3 / 3-1 | 10     | **+5**   |
| 9z       | 0-3 / 3-0 / 2-2 / 3-1 | 8      | **+2**   |
| Imperial | 3-0 / 1-3 / 3-1 / 1-3 | 8      | **+1**   |
| EF       | 1-3 / 3-1 / 3-1 / 1-3 | 8      | **0**    |
| DENDELE  | 3-0 / 0-3 / 2-2 / 1-3 | 6      | **−2**   |

看「胜场和」那列: 9z、Imperial、EF 三队都是 8 分，**完全并列**，排不出先后。

看「净胜场和」那列: 分别是 +2、+1、0，高下立判。

这个差别很关键。举个最直观的: 你打过的对手里有一支 3-0 全胜、一支 0-3 全败，
按「胜场和」算是 3 + 0 = 3 分，看起来很一般；但按「净胜场」算是 +3 和 −3，合计 0，
而如果你打的对手是两支 2-1，净胜是 +1 +1 = +2 ——后者反而更高，因为你碰到的都是硬茬。

### 第四步：配对

组内排序完成后，按「首尾配对」打:

```
第 1 名  vs  第 6 名
第 2 名  vs  第 5 名
第 3 名  vs  第 4 名
```

排名最高的打排名最低的。4 队组就是第 1 打第 4、第 2 打第 3。

上面那 6 队排完序就是 FaZe → M80 → 9z → Imperial → EF → DENDELE，
首尾配对得到:

```
FaZe     vs  DENDELE
M80      vs  EF
9z       vs  Imperial
```

**如果这么配会撞上已经打过的对手**，就往下顺延一个没打过的。实在排不开（比如组里只剩
打过的那一支）才会允许重赛。

### 第五步：谁赢？

模拟器里能改每一场的胜负，改完之后后面所有轮次都会重新算一遍。

如果某场比赛**还没有真实结果**，模拟器默认让**种子更高的一方获胜**——种子是赛前的排名，
种子号越小越强。这样在比赛开始前就能看到一条完整、合理的推演路径。

### 常见疑问

**为什么改了第 1 轮一场，第 5 轮的对阵全变了？**
因为第 1 轮的结果会改变第 2 轮的战绩分组，进而改变第 3 轮的对手、改变第 4 轮的 Buchholz 分、
再改变第 5 轮的排序。瑞士轮是环环相扣的，牵一发而动全身。

**为什么我的队伍明明赢了，排名却下降了？**
排名比的是 Buchholz（对手强度），不是你自己赢了几场。赢的场次只决定你在哪个组，
组内的位置取决于你的对手有多强。
